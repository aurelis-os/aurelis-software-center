Features Implemented:
---------------------
1. File Detection (detect.py):
   - Detects AppImage files (in applications_dir or via desktop entry)
   - Detects Flatpak applications (via desktop entry in export dirs)
   - Detects Pacman packages (system vs user via JSON lists)
   - Returns DetectionResult with kind, id, and name

2. InstallWizard (install_wizard.py):
   - Two-page wizard (action selection, progress/result)
   - Routing: auto-runs AppImages already in applications_dir
   - "Run without asking" feature with SHA256 tracking
   - Install action calls backend.install_async for AppImages
   - Flatpak installation via QProcess
   - Just run with optional "Don't ask again" checkbox

3. UninstallWizard (uninstall_wizard.py):
   - Detects application type on startup
   - System package refusal page (single page, Close only)
   - Unknown file explanation page
   - Two-page wizard for removable applications (confirm, progress)
   - AppImage removal via backend.remove_async with trash action
   - Flatpak removal via QProcess
   - Pacman user package removal with restart note

4. CLI Integration (__main__.py):
   - wizard install <path> subcommand
   - wizard uninstall <path> subcommand
   - Minimal initialization (no catalog loading, no main window)
   - Appropriate backend selection based on file type

5. Settings Integration (settings_dialog.py):
   - "Wizards" section with "Run without asking" list
   - List widget showing app_id for each entry
   - Remove button for each entry to clear from config

6. Desktop Files:
   - aurelis-software-wizard-install.desktop (MIME handler for .AppImage, .flatpakref, .flatpak)
   - aurelis-software-uninstall.desktop (Dolphin service menu for right-click uninstall)
